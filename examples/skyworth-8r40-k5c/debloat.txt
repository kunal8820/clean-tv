# Skyworth / Coocaa 8R40_K5C (Realtek rtd285x, 1 GB RAM, 32-bit), Android 8.0 (API 26), build OPR6.170623.012
# Mainland China domestic firmware (com.tianci.* / com.coocaa.* family), NOT the Google-TV
# Skyworth in examples/skyworth-sw-22sa (that one is com.smartdevice.*, Android 14).
# Stock launcher: com.tianci.movieplatform (boot target set in /system/pcfg + /system/etc/bootintent.xml, DO NOT DISABLE).
# Live TV / System UI: com.skyworth.tv (DO NOT DISABLE).
# If you pass package names to tools/restore.sh or launcher/build-and-install.sh, use the two above.
#
# Apply:    TV_HOST=<tv ip> tools/disable.sh examples/skyworth-8r40-k5c/debloat.txt
# Undo:     TV_HOST=<tv ip> tools/restore.sh examples/skyworth-8r40-k5c/debloat.txt
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# CRITICAL SAFETY TRAPS (READ BEFORE USING). Full details: docs/devices/skyworth-8r40-k5c.md
# 1. The ONLY ADB toggle lives inside Settings > 基本设置 > 设备信息 (About this TV) > 更多信息.
#    That page crashes if these are disabled together:
#      com.tianci.de
#      com.skyworthdigital.stb.dataprovider
#      com.coocaa.sky.ccapi
#    A crashed About page means ADB can never be re-enabled: factory reset is the only way out.
#    BEFORE debloating, install Activity Launcher (de.szalkowski.activitylauncher.oss) and confirm you
#    can open com.tianci.setting/.factorysetting.FactorySetting (action coocaa.intent.action.TIANCI_FACTORY).
#    Apply in small batches and re-open the About page after each batch.
#    com.tianci.de alone is fine (About, device info and the factory menu all render; ~70 MB freed in two
#    processes), but never batch it with the other two on this line. See "optional additions" at the end.
# 2. DO NOT DISABLE com.tianci.movieplatform (stock launcher) or any other current launcher.
#    The boot target comes from read-only /system/pcfg (DEFAULT_HOMEPAGE) and the rule table
#    /system/etc/bootintent.xml; disabling the launcher gives a black screen on boot
#    (sys.boot_completed never set). To actually change the launcher, edit those two files instead
#    (needs root) - "Replacing the stock launcher" in the device guide.
# 3. Do not touch persist.service.homepage.* props. Setting persist.service.homepage.switch 0 stopped
#    adbd from starting after reboot on the reporter's unit.
# 4. ADB has to be switched on again after every reboot on this firmware: adbd is a `disabled` service
#    in /init.usb.rc, so nothing starts it at boot. That is normal, not a debloat casualty.
# 5. If an accessibility helper is on, apps with a text field can crash: this firmware has no clipboard
#    service and Android 8's TextView.canPaste() does not null-check it. It shows up as "the app reloads
#    its home page" when you open search. Nothing in this list causes it; turn the helper off.
#
# Boot ad (not a package, run once over ADB, survives reboot):
#   tools/tv.py 'setprop persist.sys.bootvideo.time 1'

# Boot ads and autostart queue (disabled from the factory on many units, zero risk)

# disabling com.coocaa.sky.ccapi "and/or" this package. Disable it LAST and re-check About.
com.tianci.user            # Account management
